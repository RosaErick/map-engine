# How to install

[Português](pt.md) · **English** · [Español](es.md)

You do not need to know how to code. Pick **one** of the two paths.

> Use **Google Chrome** or **Microsoft Edge**. The tool relies on features that only
> exist in those two. It opens in Firefox and Safari, but parts will be missing.

---

## Path 1 — Install it as an app (recommended)

The easiest one, and the one that works best: the browser keeps the tool on your machine
and it starts behaving like a program, with its own icon and **no address bar**. Once
installed, it works with no internet.

1. Open the tool's address in Chrome or Edge.
2. On the right-hand side of the address bar an **install** icon appears (a monitor with
   a downward arrow). Click it.
   *(If it does not show up: menu ⋮ → **Cast, save and share** → **Install page as app**.)*
3. Confirm with **Install**.

> 📷 *screenshot: the address bar with the install icon highlighted*

That is it. The tool now has an icon in the start menu (Windows) or the Launchpad (Mac),
opens in its own window and **keeps working with the internet switched off**.

To uninstall: open the tool, menu ⋮ → **Uninstall**.

---

## Path 2 — Download one file and carry it on a USB stick

For a machine that will never have internet, or to take the tool to a venue without
depending on a network.

1. Go to **[Releases](../../../../releases)** and download **`projection-mapping.html`**.
   *(Or, with the tool already open, click **download for offline use** in the top bar.)*
2. Copy the file wherever you like — a USB stick, the desktop, anywhere.
3. **Double click** it. It opens in the browser and already works.

> 📷 *screenshot: the file on the desktop and the tool open*

It is a single file with everything inside, around 285 KB. It installs nothing, needs no
server and never touches the internet.

**One limitation of this path:** opened straight from a file, the tool may ask for camera
and screen-capture permission **every time**, because the browser cannot remember the
authorisation. If you use the camera or screen capture often, prefer path 1.

---

## First steps, once it opens

1. **open folder** — pick an empty folder for the project. That is where the project file
   and the videos and images you use will live. Everything saves on its own.
2. **match this screen** — choose the projector and click. This makes the tool work at the
   projector's exact resolution.
3. **+ surface** — a rectangle appears. Drag its four corners until they cover the real
   object being projected on.
4. Drag a video or an image **onto the surface** to fill it.
5. **send to projector** — the projection goes to the projector; the controls stay on the
   laptop.
6. Press **H** — hides the whole interface. Press **H** again to bring it back.

> 📷 *screenshot: the four corners being dragged over an object*

**The adjustment that makes the difference:** click a corner and use the **arrow keys** to
move it one pixel at a time (with **Shift**, ten pixels). That fine tuning is what
separates “almost aligned” from aligned.

The full guide lives inside the app, under **guide** in the top bar.

---

## If something goes wrong

| What happens | What to do |
|---|---|
| The **open folder** button is greyed out | You are not on Chrome or Edge. Switch browsers. |
| The output window does not open | The browser blocked it. Allow pop-ups for this address and try again. |
| The output does not go fullscreen | Click the output window and press **F11**. |
| A surface shows magenta stripes | The media file left the project folder. Put it back, or use **relink** to point it at another file. |
| The camera does not open | Another program may be using it. Close the other one and reload. |
| The image disappeared after moving the window | Press **fit view** in the top bar. |
